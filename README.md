# shavit-camangle

shavit timer styles where others and replays see you turned (sideways, half-sideways, backwards, custom) while you play normally.

Requires SourceMod 1.12+ and shavit 3.x.

## Install

1. Copy `plugins/shavit-camangle.smx` to `addons/sourcemod/plugins/`.
2. Paste `configs/shavit-camangle-styles.cfg` into `shavit-styles.cfg`, numbered after your last style.
3. Restart the server.

## Commands

- `!cam`: menu
- `!camangle <degrees>`: custom angle (+ left, - right)
